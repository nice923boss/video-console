# KTV 歌詞範例：Video Console 的 AI 助理照這個格式上 KTV 歌詞字幕
#
# 用法
# 1. 把下面的範例歌詞換成你的歌詞，存成文字檔（記事本預設的 UTF-8 即可）。
# 2. 歌曲先放上時間軸，畫面（影片或背景圖）要放到歌曲結束。
# 3. 把檔案拖進 AI 助理面板（或按上傳），訊息輸入「用 @檔名 上 KTV 歌詞字幕」。
#
# 格式
# 1. 一行一句，照實際演唱的斷句換行；一句建議 12 字以內，太長畫面會換行。
# 2. 上下兩行輪流：第 1、3、5 句在上行（置左），第 2、4、6 句在下行（置右）；
#    停頓超過 6 秒（例如間奏）之後，下一句重新從上行開始。
# 3. 重複的副歌唱幾次就寫幾次，不要寫「副歌 x2」。
# 4. 只寫唱出來的字：和聲、口白、（間奏）這類沒唱的說明請刪掉，或在行首加 #。
# 5. 字要跟演唱一致，同音字也要寫對，對齊才準；對不上的句子會先關閉，再到時間軸檢查。
# 6. [主歌]、[副歌]、[Verse]、[Chorus] 這類段落標記與空白行不會上字幕，可以保留。
# 7. 行首是 # 的是說明，不會上字幕，這幾行可以留著。

[主歌]
清晨的海風輕輕吹
浪花把腳印帶回海裡
我們沿著沙灘慢慢走
把今天的心情說給你聽

[副歌]
唱吧 讓歌聲飛過天邊
唱吧 讓笑容留在身邊
不管明天在哪裡
這首歌陪你一起

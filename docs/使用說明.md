# Video Console 使用說明

安裝、第一次設定與疑難排解請看 [README](../README.md)。這份說明介紹日常剪輯操作。要讓 Claude Code 幫你操作 VC，請看 [CLAUDE_SETUP.md](CLAUDE_SETUP.md)。

## 畫面配置

左側導覽列由上而下：

| 頁面 | 快捷鍵 | 用途 |
|---|---|---|
| 專案 | Alt+1 | 新增、開啟、複製、刪除專案；垃圾桶 |
| 分鏡 | Alt+2 | 鏡頭卡片、提示詞、AI 生圖生影片、版本 |
| 剪輯 | Alt+3 | 時間軸、預覽、字幕、聲音 |
| 素材 | Alt+4 | 匯入的檔案、輸出成品、字幕檔與鏡頭清單下載 |
| 佇列 | Alt+5 | 背景工作（匯入、轉字幕、輸出…）的進度 |
| 引擎 | Alt+6 | ComfyUI、雲端 API、配音、語音轉字幕 |
| 設定 | Alt+7 | 新專案預設、快捷鍵、依賴元件、版本紀錄 |
| 說明 | Alt+8 | 這份使用說明，左側列出章節；也能開快捷鍵一覽、剪輯功能說明、新手導覽 |

右上角的「輸出影片」按鈕開啟輸出對話框。按 `?` 看全部快捷鍵，Ctrl+Shift+P 開指令面板。這份使用說明在 APP 左側導覽列的「說明」頁也看得到，內容與 docs 資料夾裡的這個檔案相同。剪輯功能與目前的按鍵另外整理在「剪輯功能說明」：快捷鍵一覽下方的按鈕、「說明」頁左上方，或在指令面板搜尋「剪輯功能說明」。

## 1. 新增專案

「專案」頁按「新增專案」：

- **專案名稱**
- **畫面比例**、**輸出尺寸**：例如 16:9、1920×1080
- **影格率**：24、25、29.97、30 fps。攝影機錄的 29.97 fps 素材選 29.97，輸出就是標準的 29.97（30000/1001）
- **風格預設**：AI 生成用，剪實拍素材選「不套用」

建立後都能在專案設定修改：「分鏡」頁上方按「專案設定」，右側面板會顯示風格、畫面尺寸與影格率；點任一鏡頭卡片就回到鏡頭屬性。預設值在「設定 › 新專案預設」。

## 2. 匯入影片

- **放進鏡頭**：把檔案拖到「分鏡」頁的鏡頭卡片上，成為該鏡頭的新版本。新專案有一個空白鏡頭，第一支影片拖到它上面即可。
- **放到時間軸**：圖片與影片拖到「剪輯」頁時間軸的上層軌或「新增軌道」列成為疊加畫面（落點已有片段時放到該軌最近放得下的空位，素材庫選單的「放到畫面 N」也一樣），拖到其他位置（畫面軌、音軌、空白處）都會變成新鏡頭，插在放下位置最近的鏡頭交界；聲音檔拖到哪條音軌就放在那條（那段時間已有聲音時自成一條新音軌）。
- **素材庫**：「素材」頁按「匯入檔案」，之後在檔案上按右鍵選「設為鏡頭的影片…」或「穿插為新鏡頭…」；要用拖的，到「剪輯」頁打開素材清單（見下方）。

支援格式：影片 .mp4 .webm .mov .mkv .m4v .avi；圖片 .png .jpg .jpeg .webp .bmp .gif；聲音 .mp3 .wav .m4a .aac .flac .ogg .opus。瀏覽器不能直接播的格式（例如攝影機的 MXF 轉出檔、ProRes）會自動轉檔，4K 長片轉檔很久，建議先轉成 1080p 再匯入。

透明背景的 .webm（VP8／VP9 帶 alpha，例如 Claude 用 p5.js 做的動態文字）拖到上層軌就能疊在畫面上，透明部分會透出下層畫面。放進鏡頭（畫面軌）時不保留透明。

上層片段選取後，右側「位置」有「滿版」與「填滿」：滿版顯示整張素材，比例不同時留黑邊；填滿蓋滿整個畫面，超出畫面的部分裁掉（直式素材放在橫式影片會裁掉上下）。「大小」可拉到 200%，超過 100% 的部分同樣裁掉。

**蓋滿畫面的上層片段**：不透明的影片或 JPG 蓋滿整個畫面時（透明字卡、去背、半透明、有位置或透明度關鍵幀的不算），底下空白鏡頭的「尚未產生畫面」文字卡不會燒進輸出，只在沒被蓋住的那段出現。放好、移動或修剪上層片段後，若某個有畫面的鏡頭整段被蓋住，會跳出對話框詢問是否「隱藏分鏡畫面」：隱藏後該鏡頭在預覽與輸出都是黑畫面、時間軸上變灰（同按 V 停用的樣子），但原聲照常播放與輸出，接點就不會閃出底下的畫面。之後可在鏡頭右鍵選單選「顯示分鏡畫面」還原。只蓋住一部分的鏡頭不會詢問（隱藏會讓沒蓋住的那段也變黑）。

**影格率不同的上層影片**：29.97 fps 的攝影機素材（例如 FX6）放在 30 fps 專案的上層軌，片段結尾可能差不到一格。輸出時片段會撐到它在時間軸上的結尾（以最後一格補足），前後兩段上層片段頭尾相接時，不會在接點閃出一格底下的畫面。

**輸出對齊影格**：鏡頭長度常常不是整數格（例如 30 fps 下 1.05 秒是 31.5 格）。輸出時鏡頭接點、轉場、上層片段與調整圖層的起點和終點，一律對到它在時間軸上的時間最接近的那一格，所以鏡頭再多，接點也不會越跑越偏；上層片段結尾剛好對在鏡頭接點時，下一格就是下一個鏡頭，不會多出一格底下鏡頭的畫面。字幕仍以百分之一秒計時，出現與消失可能比接點晚一格。

### 素材庫多選、標籤、重新連結

- **多選**：Ctrl 點選加選、Shift 點選連續選；上方出現「加到時間軸」（圖片與影片接在最後，聲音從播放頭開始）、「加標籤」、加入最愛、刪除。每個動作都能一次 Ctrl+Z 復原。
- **剪輯頁的素材清單**：Ctrl+Shift+1 或播放器列上的按鈕，在預覽旁顯示素材清單，同樣可以多選、拖到時間軸，雙擊預覽。
- **標籤**：素材右鍵「加上標籤」，多個標籤用逗號、頓號或空白分開（每個素材最多 20 個、每個 30 字）。工具列的標籤選單只顯示有那個標籤的素材，搜尋框也會比對標籤。
- **重新連結**：檔案搬走、或想換成新版（例如重新調光的影片）時，素材右鍵「重新連結檔案…」選新檔。新檔要同類（圖片換圖片、影片換影片、聲音換聲音）；用到它的鏡頭跟著換，可以復原，舊檔留在專案資料夾。

### 從劇本建立鏡頭

「分鏡」頁按「匯入劇本」（或指令面板的「從劇本拆解鏡頭…」），貼上劇本或開啟 .txt、.md、.csv、Word 分鏡表，選拆分方式後按「拆解成鏡頭」，在確認畫面修改、勾選後加入。

「依劇情細拆鏡頭」預設開啟，關掉就是每段劇情一個鏡頭：

- **照劇本排版拆**：分鏡表（有標題列）的每一列，或寫成編號動作（1. 2. 3.）的段落，照原文切：
  - 每個動作一鏡。動作開頭寫明景別（「(特寫)」「特寫：」「鏡頭特寫…」）就用該景別；寫到表情、眼神、哭笑時用近景，其餘中景。
  - 換場的第一鏡用全景，標籤含「空拍」（例如【空拍運鏡】）用遠景。場景欄的地點首詞改變，或畫面以「場景：」開頭才算換場；「教室」接「教室角落」算同一場景。
  - 聲部台詞依點名放到該角色出現的鏡頭，沒點名就照順序分配；同一動作放不下的台詞另給說話者一鏡，超過約 26 字的台詞切到下一鏡。說話者記在該段第一鏡的備註。
  - 備註欄的運鏡指示（「特寫阮月安的表情」「鏡頭：用廣角顯示整間教室」）另成一鏡，接在相關動作之後；動作已拍到同樣畫面就不重複。
  - 段落標籤含「幻想」「驚險」「危險」時判為緊湊；含「幻想」的段落最多 3 鏡，每鏡 0.8 秒；含「圖卡」的段落，旁白依圖卡順序分段。
  - 旁白列舉（「A、B、C。」）每項一鏡，畫面留空，請自行補上。
  - 秒數：換場第一鏡約為平均鏡長的 2 倍，特寫與說話者鏡用最短秒數，其餘用平均鏡長，都至少留到讀完該鏡字幕。
- **多景別**（沒有排版的自由文字）：每段劇情拆成 2 到 5 個鏡頭，景別不重複（遠景或全景、中景、近景、側面中景、插入特寫、特寫、反應鏡頭）。景別寫在「運鏡」欄開頭，畫面描述也以景別開頭。原文寫明景別（例如「中景：」）時，第一鏡用這個景別並保留原文畫面。
- **節奏**：依每段內容判斷，不固定秒數。衝突、驚慌、命令等字詞判為緊湊，溫暖、陪伴、靜靜等字詞判為舒緩，開場與結尾偏舒緩。緊湊段落鏡頭短（最短 0.8 秒），舒緩段落鏡頭長（最短 2 秒）。
- **旁白對齊**：旁白依停頓切到各鏡，每鏡至少留到讀完自己那段（每秒約 4 個中文字）。
- 已寫明秒數的段落維持一鏡。
- 確認畫面每鏡標「第 N 段，節奏」，段落之間多空一行。段落與節奏只在這一步參考，不會存進鏡頭。
- 選「文字模型」時由模型分段、規劃景別與節奏；秒數改用同一套規則，依模型判的節奏與旁白長度重排（模型給的秒數只當同段各鏡的長短比例）。模型把同一句旁白重複放在幾個鏡頭時，會依停頓切開；字幕開頭的「旁白：」會拿掉。模型只給一鏡的段落由規則補拆，確認畫面上方會說明補拆幾段。
- 節奏與景別是依關鍵字推斷，照排版拆讀的是格式（編號、括號、冒號），不理解劇情，請在確認畫面調整秒數、畫面描述，或取消勾選不要的鏡頭。
- 想讓 Claude 依劇情設計分鏡：用 `script-to-vc-storyboard` SKILL 把腳本轉成每列寫明秒數的 Word 分鏡表，匯入時一列一鏡，內容不會被改動（安裝方式見 [Claude 串接設定](CLAUDE_SETUP.md) 步驟 6）。

## 3. 時間軸剪輯

| 動作 | 做法 |
|---|---|
| 分割 | 播放頭移到要切的位置，按 Alt+B（或剪刀按鈕）。沒有選取時切「畫面」軌；Alt+Shift+B 把播放頭經過的每一軌一起切開。切開後的兩段各有一份版本清單（共用同一個檔案），之後可以分別換版本或重新生成 |
| 分割模式 | 按 B 進入分割模式，點片段就在點的位置切開；按 A 回到選擇模式才能拖曳與選取 |
| 修剪模式（滾動、滑動、滑移） | 按 T（或時間軸工具列中間的按鈕）進入修剪模式，只作用在畫面軌，總長度不變：拖曳兩個鏡頭之間的剪接點是「滾動」，前一個鏡頭變長、後一個變短（或反過來），其他鏡頭與字幕不動；拖曳影片鏡頭中間是「滑動內容」，鏡頭位置與長度不變，換成素材裡較早或較晚的畫面；按住 Shift 拖曳中間的鏡頭是「滑移」，鏡頭內容不變，跟前後鏡頭的剪接點一起移動。修剪模式只動畫面：上方畫面、字幕、音訊都留在原位；有原聲的鏡頭會先自動分離原聲（放在同一條音訊列），聲音保持原本的位置，一次 Ctrl+Z 連同分離一起還原；之後要讓原聲再跟著畫面，在鏡頭右鍵選「還原原聲」。拖曳時提示列顯示移動秒數與新的入點、出點，素材用完就停住；按 Esc 取消，Ctrl+Z 復原。修剪模式下轉場標記不能點，要改轉場先按 A 回選擇模式 |
| 修剪 | 拖曳片段左右邊緣；或按 F1（剪掉播放頭左邊）、F3（剪掉播放頭右邊）；或在右側「剪輯」分頁「剪輯點」輸入入點、出點 |
| 移動 | 拖曳片段中間，調整順序。畫面軌修剪後後面的鏡頭會自動補上空隙 |
| 不重疊 | 同一軌的上層畫面、音樂、音效片段不會疊在一起：拖到別的片段上時，放到最近放得下的空位，頭尾與相鄰片段對齊；拖曳邊緣修剪碰到相鄰片段就停住，提示列會顯示「對齊相鄰片段」或「碰到相鄰片段」。配音軌照字幕自動排列，不受這條限制 |
| 換軌 | 把上層畫面、音樂、音效片段拖到另一條軌道時，只放進放下位置那段空位，頭尾與相鄰片段對齊；那段空位不夠長時，片段變成紅色虛線，提示「這條軌道在這裡沒有足夠的空間」，放開不會移動。要放進去，先在該軌騰出空間，或拖到「新增軌道」列開一條新軌 |
| 移到上層軌 | 把畫面軌的鏡頭往上拖到上層畫面軌（或「新增軌道」列），鏡頭變成上層片段，原位留一個同長度的「空白」鏡頭，後面的鏡頭與字幕都不動。上層軌在落點沒有足夠空位時不會移動（同「換軌」）。變速或已分離原聲的鏡頭要先還原 |
| 刪除 | 選取片段按 Delete 或 F2。刪除鏡頭前會先確認（可在設定關掉） |
| 停用 | 選取片段按 V。停用的鏡頭保留位置，預覽與輸出都是黑畫面加靜音；再按一次恢復 |
| 隱藏分鏡畫面 | 鏡頭右鍵選單「隱藏分鏡畫面（原聲保留）」：畫面在預覽與輸出都是黑色、片段變灰，原聲照常播放與輸出。給整段被滿版上層片段蓋住的鏡頭用（蓋住時會自動詢問）；右鍵選「顯示分鏡畫面」還原 |
| 右鍵選單 | 在時間軸任一片段（鏡頭、上方畫面、音訊、字幕、調整圖層）按右鍵，列出這種片段能用的操作與快捷鍵：複製、在播放頭貼上、在播放頭分割、停用（音訊為靜音、字幕為隱藏）、以片段設定區域、刪除、漣漪刪除；鏡頭另有添加靜幀、分離或還原原聲、倒放、變速、隱藏或顯示分鏡畫面與標籤顏色，上方畫面的影片片段另有添加靜幀，上方畫面、音訊、調整圖層另有添加關鍵幀。目前做不到的項目會變灰，滑鼠停在上面說明原因（例如播放頭不在片段上）。時間軸上不會出現瀏覽器的右鍵選單 |
| 多選 | 畫面軌、原聲列或音訊軌上，按住 Ctrl 點片段逐一加選，再點一次取消；先點一個片段，再按住 Shift 點後面的片段，同一軌中間的片段全部選取。選到的都會標示，右側面板可以一起調原聲音量、批次防抖、「刪除 N 個鏡頭」；多選音訊片段則一起調音量 |
| 縮放 | F6 放大、F5 縮小、Shift+Z 符合視窗寬度、Alt 或 Ctrl＋滑鼠滾輪 |
| 捲動 | 滾輪上下捲動軌道，Shift＋滾輪左右捲動；軌道沒有超出高度時滾輪直接左右捲動 |
| 軌道高度 | `+` 增高、`_`（Shift+-）降低 |

**連動上下軌**（鎖鏈圖示，Shift+N，預設開）：鏡頭移動或改長度時，字幕、上層畫面、調整圖層、音樂、音效跟著移動；刪除鏡頭時，整句落在鏡頭上的字幕會一起刪除，鏡頭上方的上層畫面、音樂、音效也一起刪除；跨過鏡頭頭尾的片段只剪掉鏡頭範圍那一段，留下的部分跟著後面的鏡頭往前補，不會疊在一起。只是把鏡頭「移出輸出序列」不會刪字幕。

**磁吸對齊**（磁鐵圖示，N）：拖曳時貼齊其他片段，按住 Alt 暫停。

### 區域與時間軸標記

| 動作 | 做法 |
|---|---|
| 設定區域 | I 設入點、O 設出點，尺規上出現區域條；Shift+X 把區域設成選取片段（或播放頭下方鏡頭）的頭尾 |
| 播放、清除區域 | Shift+Enter 從入點播到出點後停下；Alt+X，或時間軸工具列連動按鈕右邊的「清除區域」（中括號加叉），清除入點與出點 |
| 新增標記 | M 在播放頭加一個標記；播放頭停在標記上按 Alt+M 切換顏色（藍、紅、橘、黃、綠、紫） |
| 跳到標記 | F7 前一個、F8 下一個，時間軸自動捲到標記在畫面正中央；或點尺規上的標記。標記上按右鍵可換顏色或刪除 |

### 速度、倒放、定格

| 動作 | 做法 |
|---|---|
| 變速 | Ctrl+R 開右側「速度與方向」，選 0.25x 到 4x。時間軸長度跟著改，聲音一起變速 |
| 倒放 | Ctrl+Shift+R。第一次會在背景產生倒放影片（「佇列」看進度），完成後自動換上；之後再按在正放、倒放間切換 |
| 定格（添加靜幀） | Alt+F，或在鏡頭、上方影片片段上按右鍵選「添加靜幀（5 秒）」，在播放頭插入 5 秒靜止畫面，該鏡頭後段畫面接在靜幀之後；播放頭在片段頭尾時，定格加在前面或後面。選取上方畫面的影片片段（字卡、B-roll）時，定格加在同一軌，片段後段往後移 5 秒；同一軌後面的片段不會跟著移，所以片段後面要有 5 秒空位。定格畫面由背景工作擷取，完成後才出現在時間軸（一次 Ctrl+Z 就還原）；透明背景的影片定格後仍然透明；定格取當下的位置、大小與透明度，不帶關鍵幀；圖片本來就是靜止畫面，不能定格 |

### 防抖

- **勾選防抖**：選取鏡頭，右側「剪輯」分頁勾選「防抖」。第一次會在背景處理（「佇列」看進度，勾選框顯示「防抖處理中」），完成後自動換上防抖後的影片，預覽與輸出都用它。
- **處理範圍**：只處理目前的剪輯範圍，前後各多留 1 秒；修剪可以在多留的 1 秒內拉長，要更長就取消勾選、改好修剪、再重新勾選。
- **黑邊**：畫面會依晃動程度自動放大，裁掉晃動造成的黑邊，邊緣會少一些畫面。
- **取消**：取消勾選換回原始影片，剪輯範圍不變；再勾一次直接用做好的防抖影片，不用重做。
- **批次防抖**：畫面軌或分鏡上多選鏡頭，右側「防抖」區塊顯示已防抖幾個，按「全部防抖」一次處理還沒防抖的影片鏡頭（已做過的直接換上，其他排進佇列），按「全部取消防抖」全部換回原始影片；一次 Ctrl+Z 復原換版本的部分。沒有影片的鏡頭與還在處理中的鏡頭會略過。
- **上層畫面片段**：B-roll 等上層畫面的影片片段也能防抖，選取片段後在右側「去背」下方勾選「防抖」，做法同上。防抖後的影片會放進素材庫，名稱加「（防抖）」；在素材庫刪掉它，用到它的片段會一起移除（可按復原）；原始影片刪掉後就不能取消防抖。
- **效果**：靠分析畫面內容（不是攝影機的陀螺儀資料），強度固定。手持的輕微晃動改善有限（實測晃動量減少約 1～2 成）；水面、人群等大面積在動的畫面可能幾乎沒有改善。
- **需要的元件**：ffmpeg 要含 libvidstab，沒有時會提示到「設定 › 影片輸出」指定。

### 分離原聲與音量

- **分離原聲**：選取鏡頭按 Ctrl+Shift+S，原聲變成音訊軌上的片段，鏡頭本身改成無聲，之後就能單獨修剪、淡入淡出、加音量關鍵幀；鏡頭原本設的原聲音量會帶到這段音訊。對已分離的鏡頭或那段音訊再按一次就還原。變速中的鏡頭也能分離，音訊片段照同樣速度播放；分離期間不能改速度。已分離的鏡頭可以定格（原聲在定格處切開、後段跟著後移）與倒放（只倒放畫面，原聲照常順向）。
- **原聲音量**：不用分離。選取鏡頭，右側「剪輯」分頁拉「原聲音量」，100% 是原始音量，最高 400%，0% 等於靜音（背景音樂也不會為它避讓）。原聲列片段名稱旁顯示不是 100% 的音量，波形跟著縮放。只調一段（例如刪掉講者的贅詞）用下面的原聲關鍵幀，不用分離、不動畫面。
- **壓低爆音**：時間軸波形超過滿格的地方畫成紅色，代表輸出會破音。選取鏡頭，右側「剪輯」分頁「原聲音量」下按「壓低爆音」，自動找出這段鏡頭內變紅的地方，只把那幾段壓到剛好不爆音（前後各 0.1 秒漸變），其他地方維持原音量，紅色隨即消失；按「移除壓低」或 Ctrl+Z 還原。音訊片段（含分離出來的原聲）在右側音量下方也有同一顆按鈕，壓低疊在原本的音量關鍵幀上，自己加的關鍵幀保留。改了原聲音量、把修剪拉長，或換了版本（防抖、倒放、其他版本）之後要再按一次；分離原聲時壓低會一起帶到音訊片段，鏡頭移到上方軌時不會帶過去。只看單一片段，多條音軌疊在一起的總音量仍可能超過，請看音量表。
- **原聲關鍵幀**：選取鏡頭，播放頭移到要變的位置按 K，原聲列片段下緣出現菱形。例如要靜音一段贅詞：在贅詞前後各按兩次 K（共四個點），再把中間兩點之間的音量線往下拉到底。右側「剪輯」分頁「原聲音量」下方有「播放頭位置的音量」滑桿與關鍵幀清單，可跳到、刪除或全部清除；「原聲音量」滑桿仍是整段一起放大縮小。關鍵幀記在版本上（影片檔時間），修剪移動不受影響；分離原聲時一起帶到音訊片段，鏡頭移到上方軌時不會帶過去。和「壓低爆音」相乘，兩者在關鍵幀時間點完全一致，中間以直線近似。
- **批次調原聲音量**：在畫面軌或原聲列用 Ctrl 點選逐一加選，或先點一個再按住 Shift 點另一個，選取中間所有片段；右側「原聲音量」拉一次全部套用，也可按「全部靜音」「恢復原音量」，一次 Ctrl+Z 復原。沒有聲音或原聲已分離的鏡頭會略過。
- **音量**：選取音訊、上方影片或鏡頭，Ctrl+. 加 1dB、Ctrl+, 減 1dB。設了區域時只調區域內（自動在區域兩端加關鍵幀，前後各 0.1 秒漸變）；鏡頭原聲只能整段調，只調一段請用原聲關鍵幀或先分離。
- **音量表**：時間軸右側的左右聲道音量表顯示預覽播放時的峰值，綠色低於 -6dB、黃色 -6～0dB、紅色超過 0dB（輸出可能破音）。白線是最近的最高點，停 1.5 秒後慢慢落下；上方數字是白線位置的 dB 值，超過 0dB 變紅，點一下重設。Ctrl+Shift+8 或播放器列上的小音量表可以顯示或隱藏。音量表量的是混音本身，播放器的音量滑桿不影響讀數。第一次按播放前不會動。
- **示波器**：Ctrl+Shift+7 或播放器列上的示波器按鈕，在預覽右側顯示「亮度波形」與「向量儀」，每秒更新 10 次，停格時也能看。亮度波形由左到右對應畫面的左到右，高度是亮度（0 全黑、100 全白），貼近頂端或底部表示亮部或暗部可能爆掉；向量儀越往外越飽和，方向代表色相，方塊是 75% 標準色的位置，斜線是膚色線（人的膚色通常落在附近）。量的是預覽畫面，含鏡頭調色、調整圖層、轉場與子母畫面，不含字幕、模糊或馬賽克遮罩與片頭片尾淡入淡出；輸出影片的顏色可能有些微差異。
- **匯入音量**：匯入聲音檔（拖進時間軸、素材庫或分鏡，或按匯入選檔）時先跳出「匯入音量」：+6dB（音量偏小的 AI 配音，例如 VoAI 網頁版）、0dB、-10dB（背景音樂），或在「其他」輸入 -30～+12dB。一次匯入多個聲音檔時全部套用同一個音量；只改片段音量，不改原始檔；下次會先選上次的選項。按取消時聲音檔不匯入，同批的圖片與影片照常匯入。
- **VoAI 配音**：人物用 VoAI 雲端聲音時，新生成的配音片段音量自動 +6dB。

### 降噪、去回音與選聲道

處理的對象是音訊軌上的片段。鏡頭原聲要先分離：選取鏡頭，在右側「剪輯」分頁按「降噪／去回音」，還沒分離的會先分離原聲，已分離的直接選到那段音訊。選取音訊片段後，右側屬性有「聲道」「降噪」「去回音」三區。

- **聲道**：列出檔案裡每個聲道在這段片段內的音量波形、峰值與平均 dB；有多條音軌的檔案以「音軌 n・聲道 n」列出。點一個聲道，就只播放、只輸出這個聲道，聲音放在左右正中央；其他聲道不播放也不輸出，降噪與去回音也只處理這個聲道。點第一列「全部聲道（混成立體聲）」回到原本（多音軌檔案是「第一條音軌（混成立體聲）」，其他音軌不播放）。波形是開啟時算一次的總覽，不是播放中的即時音量表。
- **降噪**：
  1. 找一段只有雜音、沒有人聲的地方：把播放頭停在那裡，或用 I、O 在時間軸標出那一段（0.25 到 10 秒）。
  2. 按「取樣雜訊」，同時會開啟降噪。I、O 標記落在這段音訊上時用標記的範圍（最長 10 秒），否則取播放頭起 1 秒。取樣位置以檔案內的秒數顯示在按鈕旁，要換位置就按「重新取樣雜訊」。
  3. 調「強度」：最多把雜音壓低 30 dB。
  4. 「低頻」「中頻」「高頻」決定三個頻段（250 Hz 以下、中間、4 kHz 以上）各套用多少強度：100% 照強度降噪，0% 不處理這個頻段。人聲變悶就把高頻調低。
- **去回音**：不需要取樣，打開「開啟去回音」就從聲音本身估計房間的殘響。用的是傳統訊號處理，不是 AI 模型。
  - **強度**：去掉多少殘響，最多壓低 25 dB。
  - **乾度**：假設房間有多空。越高去掉越多，太高聲音可能發乾或出現細碎的水聲。
  - **釋放**：10 到 400 ms。越長越平順但留下較多尾巴，太短聲音會斷斷續續。
  - **低頻衰減**：最多減少 24 dB 的低頻（150 Hz 附近以下），壓低房間的嗡聲。
  - **厚度**、**明亮**：各 ±6 dB，調整 280 Hz 附近的厚度與 5 kHz 以上的亮度，補回去回音後變薄或變暗的聲音。
- **預覽試聽**：開了降噪、去回音或選了單一聲道時出現三個選項。「處理後」聽結果；「原音」聽處理前的聲音，用來來回比較，沒有補償音量差，處理後通常比較小聲；「只聽被移除的」只播放被去掉的部分，裡面聽得到清楚的人聲，就是強度太高削到人聲了。
- **處理時間**：第一次開啟，或改了取樣、乾度、釋放、聲道、開關時，背景會重新處理這段音訊，右側顯示「正在處理降噪／去回音」，處理完成前預覽播放原本的聲音。強度、三個頻段、低頻衰減、厚度、明亮立即生效，不用重新處理。輸出影片時套用同樣的設定。
- **限制**：
  - 降噪依取樣的雜訊去除持續的雜音（冷氣、電流聲、底噪），突然出現的聲響（關門、咳嗽）去不掉。
  - 去回音對很長的殘響（大廳、樓梯間）效果有限；目前沒有 AI 版的去回音。
  - 片段分割後，新的片段要各自重新處理一次。
  - 需要 numpy：Video Console.exe 已內含，原始碼版用「安裝相依套件.bat」安裝。

### 音軌

- **拖到其他音軌合併**：把音訊片段拖到另一條音軌的列上，就放進那條音軌；拖完變成空的音軌自動消失。片段只放進放下位置那段空位，頭尾與相鄰片段對齊；那段空位不夠長時不會移動。拖曳時最下方會出現「新增音軌」列，放上去就開一條新音軌。有配音軌時，片段也能拖到配音軌。
- **合併音軌**：時間軸工具列的「合併音軌」把不會同時出聲的音軌併成同一條，同時出聲的才分開放，例如配樂一條、互不重疊的音效併成一條。配音軌不參與合併。可用 Ctrl+Z 復原。
- **調整音軌順序**：有兩條以上音軌時，每條音軌名稱旁有上下箭頭，按一下和上面或下面那條交換位置。順序存在專案裡，只影響時間軸上的排列，輸出的混音不受影響；之後新開的音軌排在最下面。
- **背景音樂自動避讓**：音軌名稱旁的用途按鈕可設成「一般」「人聲」「背景音樂」（背景音樂只有音訊軌能選），選取音訊片段時右側「所在音軌的用途」也能改。人聲軌上的片段出聲時，背景音樂軌自動降低，說完再拉回；一般音軌不參與，適合放音效。配音軌預設就是人聲；原聲列可設成人聲，讓鏡頭原聲也觸發避讓。只想讓某一段算人聲時，選取那段打開「這段是人聲」。降低幅度 6、8、10（預設）、12dB，在背景音樂軌的用途選單或片段屬性選，整個專案共用。音樂在人聲開始前 0.3 秒降下、結束後 0.8 秒回到原音量，相隔不到 1.1 秒的兩句共用一次降低，不會忽大忽小。預覽與輸出都會套用；依片段在時間軸上的位置判斷，不是偵測聲音，所以片段內的停頓音樂也維持降低。靜音的片段或音軌不算人聲。「合併音軌」只把用途相同的音軌併在一起，音效不會被併進背景音樂軌。
- **複製貼上**：選取片段按 Ctrl+C，播放頭移到要放的位置按 Ctrl+V，複本從播放頭開始並自動選取。音訊片段放在新的一條音軌；原片段還在時，複本不再連到字幕或鏡頭原聲。鏡頭插在播放頭所在鏡頭的後面；上方畫面放回原本的軌道，那裡已有片段時改放在它上面新開的一軌；字幕連同它的配音一起貼上。複製的內容只存在這個頁面，重新整理後要重新複製。
- **漣漪刪除**：Shift+Delete 刪除選取的片段後，同一軌後面的片段往前補上空隙（Delete 則留下空隙）。字幕與它的配音視為一組，一起刪除、一起移動。刪除鏡頭時，即使連動上下軌關著，其他軌也會一起補位。

### 關鍵幀

- **添加**：選取片段，播放頭移到要記的位置按 K，記下片段目前的值。兩個關鍵幀之間的值會平順變化。
- **可記的屬性**：上方畫面的位置、大小、不透明度與音量；音訊的音量；調整圖層的調色；鏡頭只記原聲音量（見「原聲關鍵幀」）。鏡頭畫面與字幕不能加關鍵幀，要動的畫面放上方軌，要漸變的調色用調整圖層。
- **音量線**：音訊片段與原聲列上，有音量關鍵幀或選取時會畫一條橘色音量線（最下面是靜音，中間高度是 100%，最上面 400%），關鍵幀是線上的圓點。選取片段後上下拖曳線段：拖兩個關鍵幀之間的線，兩點一起升降；拖第一點之前或最後一點之後，只動那一點；沒有關鍵幀時調整整段音量。拉到最下面就是靜音；片段很矮，拖曳距離會放大成約 100 像素走完全高，方便微調。拖曳時顯示百分比，放開才寫入，一次 Ctrl+Z 復原，Esc 取消。
- **面板**：Ctrl+K 在右側列出片段的所有關鍵幀，可跳過去或刪除；音訊與上方畫面的清單就在「音量」下方，鏡頭的在「原聲音量」下方。有關鍵幀的欄位，拖滑桿就是改播放頭那一格的值（沒有就新增一個）。

曲線變速（Shift+B）、組合（Alt+G）、複合片段（Ctrl+Shift+G、Alt+Shift+G）、預合成（Alt+E）已保留按鍵，目前按下只會提示還沒有支援。

### 標記片段（標籤顏色與備註）

想先標出要評估的段落（例如停頓太久、講錯重來）而不急著刪：

1. 在片段上按右鍵，選標籤顏色；或選取片段後在右側「剪輯」分頁的「標記」區選顏色。
2. 在「備註」寫下原因，例如「停頓 3 秒，評估是否刪除」。滑鼠停在片段上會顯示備註。

時間軸上的片段會整段染色。顏色：無顏色、紅色、橘色、萊姆綠、綠色、藍色、紫色。顏色只是標記，不影響輸出。

Claude 的 `interview-video-edit` SKILL 用以下慣例標記：

| 顏色 | 意思 |
|---|---|
| 紅色 | 採訪者提問、倒數、NG、確認用語，建議刪除 |
| 橘色 | 停頓過長，評估是否刪除 |

### 調整圖層與調色

調整圖層本身沒有畫面，放在獨立的「調整圖層」軌（畫面軌上方）。它涵蓋的時間內，主畫面與上方畫面軌都會套用同一組調色，字幕不受影響。

**加入**：「畫面」軌名稱右邊的彩色 + 按鈕。

- 點一下：蓋住播放頭所在的那個鏡頭。
- 按住拖到時間軸上的某個鏡頭再放開：蓋住那個鏡頭。

加入後會自動選取並打開右側調色面板。拖曳片段移動、拖曳左右邊緣改長度，和其他片段一樣可以分割（Alt+B）與刪除（Delete）。

**調色面板**：

| 區塊 | 用法 |
|---|---|
| 色輪（全局、陰影、中間調、高光） | 拖曳中間的色點往某個顏色偏；左側直條是飽和度，右側直條是亮度。雙擊色輪或直條歸零，右上角按鈕重設該色輪 |
| 色溫 | 5000 為原色，數值越高越暖（偏橘），越低越冷（偏藍） |
| 色調 | 正值偏洋紅，負值偏綠 |
| 色相 | 所有顏色沿色環一起旋轉 |
| 混合 | 100% 完整套用，降低時與原始畫面混合 |
| 數值 | 直接輸入每個色輪的 R、G、B（-1 到 1）、飽和度（0 到 2，1 為原色）、亮度（-1 到 1） |

拖曳時預覽即時更新，放開才存檔，每次放開是一個復原步驟。「全部重設」一次清掉這個調整圖層的調色。

**停用**：面板的「停用調整圖層」只停用這一個；「調整圖層」軌名稱旁的眼睛隱藏整條軌。停用或隱藏時預覽與輸出都不套用，資料保留。

多個調整圖層時間重疊時，依開始時間先後疊加。

## 4. 字幕

- **語音轉字幕**：選取有聲音的影片片段，右側「剪輯」分頁按「語音轉字幕 › 轉成字幕」。字幕直接加到時間軸，不滿意按一次 Ctrl+Z 整批收回。需要先在「引擎 › 語音轉字幕」設定好 Speech-to-subtitle。
- **新增**：按「新增字幕」或 Alt+C，在播放頭加一句 2 秒的字幕。
- **匯入 SRT**：按時間軸工具列的「匯入 SRT」選檔，或直接把 .srt 拖進時間軸。字幕放在檔案記載的時間（從序列開頭算起），`<i>`、`{\an8}` 這類標記會拿掉，多行字幕併成一行。專案已有字幕時會問要「保留並加入」還是「取代現有字幕」。整批匯入是一個步驟，按一次 Ctrl+Z 全部收回。支援 UTF-8、UTF-16 與 Big5 編碼。視窗較窄時，工具列按鈕只顯示圖示，滑鼠停在上面會顯示名稱。左起四顆字幕按鈕的圖示：字幕框加號是「新增字幕」，畫面框裡的 T 是「標題字卡」，箭頭指進文件是「匯入 SRT」，「文 A」是「雙語字幕」。
- **編輯**：點字幕，在右側改「字幕文字」、「開始」、「結束」，或按「移到播放頭」。
- **調整時間**：拖曳字幕移動，拖曳左右邊緣改長度。碰到同一列的相鄰字幕會停住、頭尾對齊；要讓字幕重疊，拖曳時按住 Shift。
- **分割**：選取字幕按 Alt+B。
- **濃縮過長的字幕**：字數超過「顯示秒數 × 每秒 4.5 字」（空白與標點不算）時，字幕屬性會出現「字幕偏長」提示，按「濃縮…」；或從指令面板（Ctrl+Shift+P）「濃縮過長的字幕…」一次列出全部。可改成每秒 4 或 5 字，按「用文字模型濃縮」取得建議稿，可以再改字，勾選的句子按「套用」，一次 Ctrl+Z 全部收回。需要先在「引擎 › 文字模型」啟用。
- **樣式**：右側「字幕樣式」下拉選單，「編輯樣式」可改字型、大小、顏色、外框、陰影、底框、位置；「全部字幕套用此樣式」、「設為專案預設」。編輯樣式視窗左側「預設樣式」有 7 種現成樣式（常用：白字細黑框、經典白字黑框、黑底白字、黃字黑框、大字易讀、電影感細字、新聞字卡），按 + 加入專案後可再調整。
- **標題字卡**：時間軸工具列「標題字卡」或指令面板「加入標題字卡…」。左側選範本（片頭標題、章節標題、下標字卡（色塊）、下標字卡（簡潔）、角落標籤），右側改每一行的文字、文字顏色與底色、顯示秒數，上方即時預覽；按「加入」放在播放頭，一次 Ctrl+Z 收回。字卡是有自己樣式的字幕，之後在字幕屬性改字、在字幕列拖曳調時間，「編輯樣式」改顏色（同樣式的字卡會一起變）。字卡會燒進輸出影片，不會寫進 SRT；匯入 SRT 選「取代現有字幕」時字卡保留。下標字卡在左下角，一般字幕變成兩行時可能疊在上面，必要時把字幕改到上方或縮短。
- **隱藏**：「字幕」軌的眼睛按鈕，隱藏時預覽與輸出都不顯示。
- **雙語字幕（中英對照）**：時間軸工具列「雙語字幕」，按「開啟檔案」選 Word（.docx）或文字檔，或直接貼上文字。格式是一行中文、下一行它的英文翻譯（翻譯分成兩段也可以），空行與項目符號會略過。英文可選一句最多兩行或單行；中文放「中文」軌、英文放下面的「English」軌，畫面上中文在上、英文在下。勾「匯入後用語音對齊到影片」會在背景辨識影片裡說的話，把每句字幕移到說出來的位置，英文跟著中文移動。專案還沒有鏡頭時，字幕先依閱讀速度接續排列。整批匯入一次 Ctrl+Z 收回。左右兩欄的表格排版不適用，請改成上下交錯的段落。
- **字幕軌選項**：每條字幕軌名稱旁的「⋮」按鈕：「語音對齊」依影片裡說的話重排這條軌的字幕時間（成對的另一種語言跟著移動，對不上的句子會排在空檔並先停用，請檢查後再開啟）；「重新命名」；「刪除軌道」連同軌道上的字幕一起刪除，可復原。眼睛按鈕只隱藏那一條軌，例如只輸出中文字幕時把 English 軌關掉。
- **AI 助理**：預覽下方控制列右側的機器人按鈕或 Ctrl+Shift+9，在預覽右邊開對話框，用一般的話交代要改什麼（例如「列出目前的字幕，找出錯字並改正」），文字模型會讀取專案、剪輯與上字幕。按上傳圖示可附加中英對照的 Word 檔，請助理匯入成雙語字幕。每次修改都是一個「AI 助理：…」復原步驟，按 Ctrl+Z 可以收回；處理中可按「停止」，會在模型這一輪回覆後停下。需要先在「引擎 › 文字模型」開啟，模型要支援工具呼叫（function calling），例如 qwen3.6-35b-a3b。對話內容只保留到重新整理頁面為止。

## 5. 輸出

右上角「輸出影片」：

| 選項 | 說明 |
|---|---|
| 畫質 | 高畫質、標準、草稿 |
| 畫面比例不同時 | 完整顯示（加黑邊）或填滿畫面（裁切） |
| 編碼器 | 自動、libx264、NVENC（NVIDIA）、AMF（AMD）、Quick Sync（Intel） |
| 開頭淡入、結尾淡出 | 秒數 |
| 把字幕燒進畫面 | 預設打開。字型、大小、位置照預覽畫面：套用字幕樣式的照樣式，其餘照「設定 › 影片輸出 › 內建字幕大小」（預設 52，預覽也用這個大小），輸出對話框不用另外調 |
| 同時下載 SRT 字幕檔 | 不燒字幕時出現，按「開始輸出」時一併把 SRT 下載到「下載」資料夾 |
| 保留影片片段本身的聲音 | 實拍訪談要打勾 |

沒選平台預設時多一個「輸出尺寸」：專案尺寸、1080p 或 4K（短邊 1080 或 2160 像素，和專案同比例）。選 1080p 或 4K 時整段直接用那個尺寸合成，放大過的素材（例如 Video2X 放大到 1080P 的影片）不會先縮回專案尺寸。

按「開始輸出」，完成的檔案在「素材 › 輸出成品」。所有專案的影片、音訊與打包 ZIP 都存在同一個匯出資料夾（預設 `data\exports\`），輸出對話框下方與「輸出成品」上方都會顯示完整路徑，按資料夾圖示直接開啟。要換位置，在輸出對話框下方路徑旁按「變更」挑資料夾，或到「設定 › 影片輸出 › 匯出資料夾」填完整路徑（例如 `D:\影片輸出`）；所有專案共用這個資料夾，只影響之後的輸出，之前的檔案留在原處，仍列在輸出成品。「專案」頁「所有專案」旁有「專案資料夾」「匯出資料夾」兩個按鈕，可直接開啟。字幕另存 SRT：輸出對話框的「只下載 SRT」（不輸出影片），或「素材 › 輸出成品 › 文件 › 字幕檔 SRT」。

**批次輸出**：「專案」頁工具列的「批次輸出」勾選多個專案，畫質、輸出尺寸、燒字幕與響度一次選好，排進佇列一個接一個輸出成 MP4；淡入淡出與畫面比例用各專案自己的設定。

「打包專案」分頁可把專案打包成 ZIP；勾「完整備份（可匯入還原）」後，可在別台電腦的「專案」頁按「匯入專案」還原。在「專案」頁的專案卡片按「⋯ › 匯出專案…」，會直接開這個分頁並勾好完整備份，不用先開啟專案。

**客戶審稿**：「素材 › 輸出成品 › 文件 › 客戶審稿網頁」（或指令面板「下載客戶審稿網頁」）下載一個 .html 檔，裡面是序列中每個鏡頭的畫面（圖片或影片的代表畫面）、秒數、提示詞與字幕，不需要網路也能開。把檔案傳給客戶，客戶用瀏覽器開啟、填上名字，在想修改的鏡頭下方留言，最下面可寫整體意見，按「下載意見檔」得到一個 .json 檔傳回來；寫到一半關掉瀏覽器，同一台電腦再開會接著寫。收到後按「匯入審稿意見」（或指令面板「匯入審稿意見…」）選這個 .json：鏡頭意見出現在分鏡卡片的「客戶意見」標籤與鏡頭屬性最上方，整體意見出現在專案屬性（沒選鏡頭時的右側面板）；客戶留言後才刪掉的鏡頭，意見會放進整體意見並註明鏡頭編號。同一份檔案匯入第二次不會重複加入。處理完的意見按垃圾桶刪除；整批匯入與每次刪除都可以 Ctrl+Z 復原。

### 客戶審稿包與修改意見

**建立審稿包**：輸出對話框的「客戶審稿」分頁（或「素材 › 輸出成品 › 文件 › 客戶審稿包」、指令面板「建立客戶審稿包…」）選畫質、要不要燒字幕，按「建立審稿包」。App 重新輸出一支 MP4，和審稿網頁「審稿.html」放進匯出資料夾裡一個新資料夾（`<專案>_審稿_<日期時間>`）。專案有背景音樂時，資料夾裡多一個 `<影片名>_無配樂.mp3`（拿掉背景音樂、保留旁白與鏡頭原聲），客戶試聽新配樂時用。把整個資料夾壓縮傳給客戶。

**客戶在審稿頁做的事**（用瀏覽器開 審稿.html，不需要網路）：

- 播放影片，看到要改的地方暫停，用「上一格」「下一格」對準畫面，按「在這一格加意見」。
- 在畫面上畫框線、箭頭、放文字，再寫下要怎麼改。
- 按「插入圖片」或「插入影片」放自己的素材，從這一格開始播，後面的畫面往後移。播放時上方預覽會在插入點暫停原片，播完插入的素材（圖片照設定的秒數）再接回原片，客戶可以先看效果。
- 「更換配樂」區塊：按「上傳配樂」選音檔，用音量滑桿調到想要的大小，可寫說明（只給製作方看）。上方預覽會改播新配樂，加上無配樂音軌裡的旁白與原聲。按「移除」回到原本的配樂。
- 最下面可寫整體意見。填上稱呼，按「打包回傳」，下載一個 ZIP（修改意見.json 加「附件」資料夾）傳回來。
- 寫到一半關掉，用同一台電腦、同一個瀏覽器再開會接著寫。

**載入修改意見**：上方工具列「修改意見」（或「素材 › 輸出成品 › 文件 › 修改意見」、指令面板「修改意見…」）按「載入 ZIP…」選客戶回傳的 ZIP；已經解開的話按「選資料夾…」。載入後會問「要複製成新專案再修改嗎？」：選「複製新專案」會建立「<專案>（<客戶稱呼>修改）」，這一輪意見移到副本並開啟副本，原版本不變；選「直接改這個專案」就留在原專案。同一份重複載入會提醒，要重載先按「移除這一輪」。每一輪都記在專案裡，上方下拉選單切換。

**逐條審核**：左側列出每一條意見（整體意見排最前面），右側顯示客戶標註的那一格畫面（框線、箭頭、文字疊在影片上）、附件預覽與客戶原話。每條選：

| 選項 | 套用時 |
|---|---|
| 同意修改 | 照客戶原話改 |
| 微調 | 照客戶原話，加上你在「補充指示」寫的要求改 |
| 不採用 | 不改 |

**套用**：按單條的「套用這條」，或底部「套用勾選的意見」一次做完全部勾了同意或微調、還沒套用的意見（從影片後段往前做，避免前面插入的鏡頭把後面的位置推掉，更換配樂排在鏡頭類意見之後、整體意見之前）。執行中可按「做完這條就停止」。

- **插入圖片、影片**：不經 AI，在那一格切開鏡頭、插入一個空白鏡頭（長度是客戶在審稿頁設定的播放秒數），素材在背景匯入。審稿後那個鏡頭被刪掉或移出序列時，標「需人工處理」。
- **更換配樂**：不經 AI。條目上顯示檔名、客戶設定的音量與客戶的說明，可以試聽。套用時刪掉原本的背景音樂（有標「背景音樂」的軌只換那幾軌，沒標就換所有不是旁白、不是鏡頭原聲的音樂軌），新配樂放在原配樂那一軌，從 0 秒開始，比影片長的部分截斷並在片尾淡出 2 秒；音量照客戶設定，客戶沒調時沿用原配樂的音量。一次 Ctrl+Z 可整個復原。配樂只能選同意或不採用，不能微調；客戶的說明不會自動執行，要照說明調整請自己改。
- **文字意見**：交給 AI 助理（要先在「引擎 › 文字模型」開啟），用助理現有的工具改。AI 看不到畫面與客戶附的圖，要看畫面判斷、要重新生成畫面、或工具做不到的事，會標「需人工處理」並寫原因；AI 回覆了但專案沒有任何變更，也標「需人工處理」。AI 標「需人工處理」或「套用失敗」時，它做到一半的修改會自動復原，結果後面註明「AI 做到一半的修改已復原」。
- 用 qwen3.6-35b-a3b 實測過的文字意見：改錯字或稱謂、改字幕內容與位置、刪除或對調鏡頭、加速、縮短鏡頭、定格指定秒數（例如「這裡停 1 秒」）、調背景音樂音量。每條約 10 到 30 秒，結果依模型而定，同一條每次可能做法不同，套用後請逐條看過。鏡頭縮短或加速後，上面的字幕長度不變，可能和下一條字幕重疊，要自己調。
- 每條的結果（已套用、需人工處理、套用失敗）與原因寫在那一條下方。失敗或需人工處理的可以改完補充指示再套用。套用的修改都能 Ctrl+Z 復原。

## 6. 復原與版本紀錄

- Ctrl+Z 復原、Ctrl+Shift+Z 或 Ctrl+Y 重做，上方按鈕會顯示下一步要復原的內容。
- 「設定 › 版本紀錄」（或 Ctrl+Shift+P 搜尋「版本紀錄」）列出自動快照，按「還原」回到當時狀態，還原後也能再 Ctrl+Z。
- **建立副本**：「專案」頁專案卡片「⋯ › 建立副本…」，輸入副本名稱（例如「第一版交稿」）。生成的圖片與影片一起複製，輸出的影片不會。副本和原專案放在同一個資料夾。
- **專案資料夾**：「專案」頁「所有專案」旁按「新資料夾」，把同一支片的不同版本收在一起。把專案卡片拖到資料夾上，或卡片「⋯ › 移到資料夾…」。點資料夾進入，按「所有專案」回上層；資料夾右鍵（或「⋯」）可重新命名、刪除，刪除資料夾時裡面的專案移回「所有專案」，專案本身不刪。搜尋會找所有資料夾裡的專案。資料夾只有一層。

## 7. 常用快捷鍵

### 工作區版面、總覽列、新手導覽

- **工作區版面**：播放器列上的版面按鈕，內建「標準」「剪輯」（時間軸加大、素材清單開）「看片」（預覽最大）三種；「儲存目前版面…」記下時間軸高度、音量表、素材清單、示波器，最多 10 個。
- **預覽解析度**：播放器列上的「預覽畫面選項」選「完整」「1/2」「1/4」，預設 1/2。選 1/2 或 1/4 時，APP 在背景替用到的影片做較小的預覽檔，播放較順、畫面不易延遲；做好前先播原檔，播放器列上的「1/2」標記滑過可看幾個影片已有預覽檔。只影響預覽，輸出一律用原檔、原尺寸。以前選過「完整」的會沿用，要改回 1/2 在同一個選單切換。
- **總覽列**：時間軸放大到看不到整段時，下方出現「總覽」條，顯示整段畫面軌的縮圖與目前看得到的範圍；按一下或拖曳跳到該處。
- **新手導覽**：第一次開 APP（還沒有專案）時自動出現，共 6 步；想再看，打開指令面板搜尋「新手導覽」。

### 預覽的聲音

- **聲音怎麼播**：預覽的聲音由 APP 自己排程（Web Audio）。每個有聲音的檔案在背景轉成一份 48 kHz 預覽音檔（放在 media/thumbs），播放時提前排好接下來 1.5 秒的聲音，片段交接處不用等影片元素起播（以前斷音的主因）。淡入淡出照輸出的直線逐樣本變化；音量、音量關鍵幀、背景音樂閃避每 10 ms 一點、點間直線變化（以前約 16 ms 一階）；單聲道素材也和輸出一樣小 3 dB。預覽音檔做好之前或做失敗時，那段聲音改回舊做法（影片元素播放），交接處仍可能斷音。
- **讀取卡住時**：預覽音檔一段超過 5 秒沒讀完就放棄、重讀一次；檔頭讀不到時那支素材先改用影片元素播放，10 秒後再試。播放中某段聲音等超過 2 秒，會在 app.log 記一筆「預覽聲音遲到」（含檔名、第幾段、等了多久、同時在讀幾段），設定頁下載的除錯資料會帶到。遇到預覽突然沒聲音，下載除錯資料就能查原因。
- **變速片段**：變速的片段另做一份同速度的預覽音檔（用和輸出相同的方式變速，音高不變），做好後一樣提前排程。慢速片段的預覽音檔較大（0.5x 約是原本的 2 倍）。有選聲道、降噪或去回音的變速片段仍用影片元素播放。
- **循環播放**：開循環時，回到開頭前先排好開頭的聲音，接點的空白較短；接點不是無縫，可能有極短停頓。播放中切換循環，聲音會重新起播一次。
- **拖播放頭聽聲音**：暫停時拖曳或點播放頭，會播放落點約 0.08 秒的聲音，方便找剪接點。不需要時在「預覽畫面選項」的「聲音」取消「暫停時移動播放頭播放聲音」。
- **J / L 倍速**：L 的 2x、4x、8x 有聲音，音高不變。J 倒轉也有聲音（倒著播）：1x 是完整的倒放聲；2x 以上每 0.04 秒接一小段倒放聲，中間的內容跳過，音高不變。沒有預覽音檔的聲音倒轉時不出聲。
- **聲音延遲補償**：藍牙耳機的聲音常比畫面慢，在「預覽畫面選項」的「聲音延遲補償」選 100～300 ms，畫面跟著延後同樣時間。APP 不會自動偵測耳機，要自己試（看嘴型對上聲音）；改用影片元素播放的聲音不跟著延後。只影響預覽，輸出不變。
- **掉格**：播放時瀏覽器來不及解碼或繪製而略過畫面，播放器列出現「掉 n 格」，滑過看說明。聲音不受影響；常出現時把預覽解析度調成 1/2 或 1/4。每次開始播放重新計算。

### 觀看模式（看 Claude 剪）

想看 Claude 剪輯的過程、又怕不小心動到專案時，按時間軸工具列右側的「觀看模式」。

- Claude 透過 API 的每次修改都會即時出現在時間軸和預覽，狀態列的「已儲存（第 N 版）」跟著增加。
- 可以照常播放、拖播放頭、點片段跳到該處、雙擊跳到片段開頭、縮放、捲動時間軸、設 I／O 範圍、跳到前後標記。
- 不能修改：按刪除、分割、復原等編輯鍵只會出現提示；拖曳片段只會移動播放頭；屬性面板、復原／重做、「輸出影片」按鈕暫時隱藏。切到分鏡、素材頁也一樣只看不改。
- 按工具列的「結束觀看」，或右上角的「觀看模式」標籤，回到一般剪輯。
- 觀看模式只對這個瀏覽器分頁有效，重新整理後仍保持；其他視窗與 Claude 照常可以修改專案。

## 8. 關閉視窗與系統托盤

- 關閉視窗後，Video Console 會留在工作列右下角的系統托盤，佇列裡的工作繼續跑。托盤圖示被收起來時，按工作列的 ^ 展開。
- 點兩下托盤圖示，或按右鍵選「開啟視窗」，重新開啟視窗。
- 要完全結束，在托盤圖示按右鍵選「結束 Video Console」；還有工作在執行或排隊時會先問要不要結束。「設定 › 系統」的「結束程式」按鈕效果相同。
- 由 Claude 或其他工具在背景啟動時沒有托盤圖示，所有視窗關閉兩分鐘、佇列也沒有工作後會自己結束。這時從桌面開啟 Video Console，會補上托盤圖示，之後就跟從桌面啟動一樣。
- 更新程式後再從桌面開啟，留在托盤的舊版會自動關掉並以新版重新啟動；舊版還有工作在執行時，會先問要不要重新啟動。

## 9. 佇列：調整順序與排程

- **調整順序**：「佇列」頁拖曳排隊中的工作，放在某列上半部排到它前面、下半部排到它後面。配音工作仍然先跑。
- **排程**：按「排程」選開始時間（例如晚上不用電腦時），可再選暫停時間。佇列先暫停，到時間自動開始，到暫停時間再暫停，執行中的工作會做完。只排一次；APP 要開著、電腦不能睡眠。手動暫停或繼續會取消排程。

## 10. 更新 Video Console 與依賴元件

- **Video Console 新版**：啟動時比對 GitHub 上的最新版本，有新版會跳出提示（同一版只提示一次），按「前往下載頁」下載。也可以到「設定 › 資料與系統」按「檢查更新」。下載新版解壓縮後，把舊版的 `data` 資料夾搬到新版 `Video Console.exe` 旁邊，專案與設定照常使用。
- **依賴元件新版**：「設定 › 依賴元件」按「檢查新版本」，APP 自己裝的 ffmpeg 或 Video2X 有新版時，那一列出現「更新到 新版本號」按鈕。放在 PATH 或其他路徑的不會更新。更新前先等用到它的工作（輸出、放大）結束。
- **下載中斷**：再按一次「重試」，從已下載的地方接著下載；一個來源失敗會自動換下一個。

## 11. 下載工作流程到自己的 ComfyUI

Video Console 呼叫 ComfyUI 用的工作流程範本可以下載下來，放到自己的 ComfyUI 單獨使用。

- **全部下載**：「引擎」頁 › 「工作流程範本」分頁，工具列按「下載全部工作流程（ComfyUI 用）」，得到「Video Console ComfyUI 工作流程.zip」。裡面每個範本（內建與自訂）一個 .json，加上「使用說明.txt」，列出每個範本需要的模型檔、要放到哪個 `ComfyUI/models` 子資料夾，範本有附的下載網址。
- **只下載一個**：範本卡片按「⋯」選「下載給 ComfyUI 用」，檔名就是範本名稱。
- **開啟**：把 .json 拖進 ComfyUI 畫面，或從左上角 C 標誌選單「檔案」>「開啟」（Ctrl+O）。節點會自動排列。
- **放進 ComfyUI 左側的「工作流程」清單**：開啟後按 Ctrl+S 存檔。直接把 .json 複製到 `ComfyUI/user/default/workflows`，從清單開啟會是空白畫面。
- **要輸入圖片的範本**（圖生圖、參考圖編輯、圖轉影片、放大）：「Load Image」節點預設填 `example.png` 當佔位，ComfyUI 沒有這張圖時節點顯示紅框，點節點上傳或選自己的圖。
- **紅框節點**：缺少自訂節點或 ComfyUI 版本太舊，用 ComfyUI Manager 的「Install Missing Custom Nodes」安裝，或更新 ComfyUI。
- 和選單裡的「匯出 JSON」不同：「匯出 JSON」含 Video Console 的欄位綁定，是給 Video Console 重新匯入用的，ComfyUI 不能直接開。
